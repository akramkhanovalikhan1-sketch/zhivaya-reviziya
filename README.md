# Живая ревизия

Сверхлёгкий ТСД + сервер 1С:Розница. Магазин не закрывается.

## Кто что делает

| | Алихан | Айдын |
|---|---|---|
| ТСД, 3 экрана, сканер, mock API | да | |
| HTTP-сервисы, регистры, АРМ, формулы чеков | | да |
| Контракт | `docs/openapi.yaml` | тот же файл |

Java/Android SDK на машине нет — ТСД сделан как веб-приложение (Chrome на терминале). DataWedge пока в режиме Keyboard Wedge (Enter после кода). Intent — следующий шаг, когда появится обёртка WebView.

## Как запустить демо

Терминал 1:

```
cd server
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Терминал 2:

```
cd tsd
npm install
npm run dev
```

- ТСД: http://localhost:5173
- АРМ товароведа: http://localhost:8000
- Swagger mock: http://localhost:8000/docs

Демо: бейдж `EMP-1001`, зона `S-01`, дрель `4600000000017`, дубль крепежа `4600000000048`, цемент `4600000000024`.
