# Живая ревизия

Сверхлёгкий ТСД + сервер 1С:Розница. Магазин не закрывается.

## Кто что делает

| | Алихан | Айдын |
|---|---|---|
| ТСД, 3 экрана, сканер, mock API | да | |
| HTTP-сервисы, регистры, АРМ, формулы чеков | | да |
| Контракт | `docs/openapi.yaml` | тот же файл |

Java/Android SDK на машине нет — ТСД сделан как веб-приложение (Chrome на терминале). DataWedge пока в режиме Keyboard Wedge (Enter после кода). Intent — следующий шаг, когда появится обёртка WebView.

## Как открыть проект на сервере 1С

Архивировать и копировать папку **не нужно**. На сервере ставишь Cursor (или уже стоит) и клонируешь GitHub.

```
git clone https://github.com/akramkhanovalikhan1-sketch/zhivaya-reviziya.git
```

В Cursor: **File → Open Folder** → папка `zhivaya-reviziya`. Это тот же проект, что у Алихана.

Дальше Айдын берёт готовые модули из `1c/` и вставляет в конфигуратор «1С:Розница» (HTTP-сервис `tsd`, регистры, АРМ). ТСД и mock можно не запускать на сервере 1С — они живут отдельно; серверу нужна папка `1c/` и `docs/openapi.yaml`.

Чтобы Айдын мог пушить правки 1С обратно: добавь его в Collaborators репозитория.

## Как запустить демо

Терминал 1:

```
cd server
python -m pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

Терминал 2:

```
cd tsd
npm install
npm run dev
```

- ТСД: http://localhost:5173
- АРМ товароведа: http://localhost:8000
- Swagger mock: http://localhost:8000/docs

Демо: бейдж `EMP-1001`, зона `S-01`, дрель `4600000000017`, дубль крепежа `4600000000048`, цемент `4600000000024`.

Итоговый факт = факт ТСД + продажи ККМ после точной секунды «НАЧАТЬ ПОДСЧЕТ» по этой зоне.
