# Шаблоны HTTP-сервиса `ТСДРевизия`

Корневой URL: `tsd`. Повторное использование сеансов: да.

На каждый шаблон повесь метод OPTIONS → `CORSOPTIONS`.

| Шаблон URL | Метод | Обработчик |
|---|---|---|
| `auth` | POST | `AuthPOST` |
| `startZone` | POST | `StartZonePOST` |
| `scanItem` | POST | `ScanItemPOST` |
| `finishZone` | POST | `FinishZonePOST` |
| `sessionLines` | GET | `SessionLinesGET` |
| `undoLast` | POST | `UndoLastPOST` |
| `ping` | GET | `PingGET` |
| `zones` | GET | `ZonesGET` |
| `arm/dashboard` | GET | `DashboardGET` |
| `arm/closeIdle` | POST | `CloseIdlePOST` |
| `arm/recheck` | POST | `RecheckPOST` |
| `arm/finalize` | POST | `FinalizePOST` |
| `arm/sale` | POST | `SalePOST` |
| `arm/applyOffset` | POST | `ApplyOffsetPOST` |
| `arm/postTransit` | POST | `PostTransitPOST` |

После публикации база отвечает по адресу:

`http://{сервер}/{база}/hs/tsd/...`

В ТСД это поле «Сервер 1С / mock» без хвоста `/hs/tsd` — клиент сам дописывает путь.
