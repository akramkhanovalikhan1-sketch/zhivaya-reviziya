# Этап 3 — в чате по одному шагу

Не делайте всё сразу. Сейчас **шаг 2**. Шаг 1 (перечисление) закрыт.

**База:** только **тестовая** копия «1С:Розница». Основную не открывать.  
**Куда писать:** расширение `ЖиваяРевизия` (префикс `зр`), не снятие с поддержки основной конфигурации.

Критерий всего этапа 3 (позже, на тестовой публикации): `GET http://{сервер}/{тестовая_база}/hs/tsd/ping` → `ok: true`.

## Шаг 1 — база кода + перечисление

### 1.1. Папка проекта

На машине с 1С (если ещё нет клона):

```
git clone https://github.com/akramkhanovalikhan1-sketch/zhivaya-reviziya.git
```

Если папка уже есть:

```
git pull
```

Архив не копировать. В Cursor: File → Open Folder → эта папка.

### 1.2. Что добавить в конфигураторе

Откройте конфигуратор **тестовой** базы «1С:Розница» (копия, не основная).

Если база на поддержке поставщика — объекты кладём в **расширение**, не в основную конфигурацию.

Окно «Новое расширение конфигурации»:

| Поле | Значение |
|---|---|
| Имя | `ЖиваяРевизия` |
| Синоним | Живая ревизия |
| Префикс | `зр` |
| Назначение | Адаптация |

ОК. В списке расширений выделите `ЖиваяРевизия` → **Открыть** (или двойной щелчок). Откроется **второе** дерево — только расширение. В корне Розницы слева ничего не добавлять.

1. В дереве расширения: **Перечисления** → правая кнопка → **Добавить**.
2. Вкладка **Основные** (имя самого объекта, не статусов):
   - **Имя:** `СтатусыЗонРевизии` (если слева само появится `зр` — не стирайте).
   - **Синоним:** Статусы зон ревизии
   - Комментарий оставьте пустым.
3. Вкладка **Данные** — сюда четыре значения. Кнопка добавить. В поле **Имя** без пробелов:

| Имя | Синоним |
|---|---|
| `Свободна` | Свободна |
| `ВРаботе` | В работе |
| `Закрыта` | Закрыта |
| `Перепроверка` | Перепроверка |

Если в дереве уже висит перечисление `Свободна` — удалите его (правая кнопка → Удалить) и создайте заново с именем `СтатусыЗонРевизии`. Статусы не пишут в поля Синоним и Комментарий на вкладке Основные.

Подключать модули и HTTP на этом шаге **не нужно**.

### Как проверить

В дереве: Перечисления → `СтатусыЗонРевизии` → 4 значения. Имена как в таблице, не «В работе» в поле Имя.

Напишите в чат **готово** (или скрин дерева) — шаг 2: регистр `СессииЗонРевизии`.

## Шаг 2 — регистр `СессииЗонРевизии`

Сначала поправьте имя значения: клик по `Вработе` → Имя `ВРаботе` (Р заглавная). Синоним: В работе.

Потом в **том же** дереве расширения:

1. Если справочника `ФизическиеЛица` в расширении нет: в **основном** дереве Розницы найдите Справочники → `ФизическиеЛица` → правая кнопка → **Добавить в расширение**. Без этого не выбрать тип сотрудника.
2. **Регистры сведений** → правая кнопка → **Добавить**.
3. Вкладка **Основные**:
   - Имя: `СессииЗонРевизии`
   - Синоним: Сессии зон ревизии
   - Периодичность: **Непериодический**
   - Режим записи: **Независимый**
4. Вкладка **Данные**:

**Измерения** (одна строка):

| Имя | Тип |
|---|---|
| `НомерЗоны` | Строка, длина 20 |

**Ресурсы** (семь строк):

| Имя | Тип |
|---|---|
| `НомерСессии` | Число, длина 5, точность 0 |
| `Сотрудник` | СправочникСсылка.ФизическиеЛица |
| `ВремяСтарта` | Дата (дата и время) |
| `ВремяФиниша` | Дата (дата и время) |
| `Статус` | ПеречислениеСсылка.СтатусыЗонРевизии |
| `ЗаблокированныйСотрудник` | СправочникСсылка.ФизическиеЛица |
| `Карантин` | Булево |

Реквизитов у этого регистра нет. Ctrl+S.

Другие регистры пока не создавайте. Скрин вкладок Измерения и Ресурсы — или напишите **готово**.
