## Шаг 26а — заимствовать `Код` у `ФизическиеЛица`

Ошибка: в расширении у `ФизическиеЛица` стоит «ввод по строке» = `Код`, а сам `Код` в расширение не добавлен.

1. Меню **Конфигурация → Открыть конфигурацию** (основная Розница, не «конфигурация базы данных»).
2. Справочники → `ФизическиеЛица` → плюсик.
3. **Стандартные реквизиты** → `Код` → правая кнопка → **Добавить в расширение** (`ЖиваяРевизия`).
4. То же для `Наименование`.
5. Заодно то же у `Номенклатура`: стандартные реквизиты `Код` и `Наименование` → **Добавить в расширение**. Иначе F7 упадёт тем же текстом на номенклатуре.

Если узла «Стандартные реквизиты» не видно: в дереве расширения откройте `ФизическиеЛица` → свойства → **Ввод по строке** (галочка «изменять») → уберите `Код`. То же на `Номенклатура`.

Не нажимать **Добавить** у справочников — так получается новый `ФизическиеЛица1`.
