# Этап 3 — в чате по одному шагу

Не делайте всё сразу. Сейчас только **шаг 1**. Написали «готово» — дадим шаг 2.

**База:** только **тестовая** копия «1С:Розница». Основную не открывать.  
**Куда писать:** расширение `ЖиваяРевизия` (префикс `зр`), не снятие с поддержки основной конфигурации.

Критерий всего этапа 3 (позже, на тестовой публикации): `GET http://{сервер}/{тестовая_база}/hs/tsd/ping` → `ok: true`.

## Шаг 1 — база кода + перечисление

### 1.1. Папка проекта

На машине с 1С (если ещё нет клона):

```
git clone https://github.com/akramkhanovalikhan1-sketch/zhivaya-reviziya.git
```

Если папка уже есть:

```
git pull
```

Архив не копировать. В Cursor: File → Open Folder → эта папка.

### 1.2. Что добавить в конфигураторе

Откройте конфигуратор **тестовой** базы «1С:Розница» (копия, не основная).

Если база на поддержке поставщика — объекты кладём в **расширение**, не в основную конфигурацию.

Окно «Новое расширение конфигурации»:

| Поле | Значение |
|---|---|
| Имя | `ЖиваяРевизия` |
| Синоним | Живая ревизия |
| Префикс | `зр` |
| Назначение | Адаптация |

ОК. В списке расширений выделите `ЖиваяРевизия` → **Открыть** (или двойной щелчок). Откроется **второе** дерево — только расширение. В корне Розницы слева ничего не добавлять.

1. В дереве расширения: **Перечисления** → правая кнопка → **Добавить**.
2. **Имя:** `СтатусыЗонРевизии` (без пробелов, точно так).
3. **Синоним:** `Статусы зон ревизии`.
4. Вкладка **Значения** — четыре строки, имена точно такие:

| Имя | Синоним |
|---|---|
| `Свободна` | Свободна |
| `ВРаботе` | В работе |
| `Закрыта` | Закрыта |
| `Перепроверка` | Перепроверка |

5. Ctrl+S. Пока **не** обновляйте базу данных, если удобнее копить объекты — можно сохранить только конфигурацию.

Подключать модули и HTTP на этом шаге **не нужно**.

### Как проверить

В дереве: Перечисления → `СтатусыЗонРевизии` → 4 значения. Имена как в таблице, не «В работе» в поле Имя.

Напишите в чат **готово** (или скрин дерева) — шаг 2: регистр `СессииЗонРевизии`.
