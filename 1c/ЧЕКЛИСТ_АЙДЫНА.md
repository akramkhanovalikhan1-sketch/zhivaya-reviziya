# Чеклист Айдына — вставка в 1С:Розница

Стартовый лист этапа 3: `1c/ЭТАП_3_СТАРТ.md`.  
Код уже лежит в `1c/`. Конфигуратор сам ничего не создаст — объекты заводятся руками, модули копируются.

## 1. Git

```
git clone https://github.com/akramkhanovalikhan1-sketch/zhivaya-reviziya.git
```

File → Open Folder → эта папка. Архив не копировать.

## 2. Объекты из `МЕТАДАННЫЕ.md`

- Перечисление `СтатусыЗонРевизии`: Свободна, ВРаботе, Закрыта, Перепроверка
- РС `ИсторияСканированияТСД`
- РС `СессииЗонРевизии` + реквизит `Карантин`
- РС `ИсторияСессийЗонРевизии`
- РС `ЗаморозкаНоменклатурыРевизии`
- РС `ГруппыАналоговНоменклатуры`

Имена полей — один в один как в таблице, иначе `Module.bsl` не встанет.

## 3. Общие модули

Создать серверные общие модули:

- `РасчетИтоговРевизии` ← текст из `1c/ОбщиеМодули/РасчетИтоговРевизии.bsl`
- `АРМРевизии` ← текст из `1c/ОбщиеМодули/АРМРевизии.bsl`

## 4. HTTP-сервис

Сервис `ТСДРевизия`, корневой URL `tsd`, повтор сеансов = да.  
Шаблоны и обработчики: `1c/HTTPСервисы/ТСДРевизия/ШАБЛОНЫ.md`.  
Модуль: `1c/HTTPСервисы/ТСДРевизия/Module.bsl`.

## 5. Заглушки, которые видит только Айдын

| Функция | Файл | Что подставить |
|---|---|---|
| `НайтиСотрудникаПоБейджу` | Module.bsl | фактический поиск бейджа в вашей Рознице |
| `НайтиНоменклатуруПоШтрихкоду` | Module.bsl | `Штрихкоды` или `ШтрихкодыНоменклатуры` |
| `НоменклатураЗаморозкиЗоны` | Module.bsl | номенклатура паллет P-01 / P-02 |
| `ПродажиККМПосле` | РасчетИтоговРевизии.bsl | если в релизе нет `ЧекККМ.Архивный` — убрать условие |

## 6. Публикация

Конфигуратор → Администрирование → Публикация на веб-сервере.  
CORS: заголовок уже ставит `ОтветJSON`, плюс OPTIONS → `CORSOPTIONS`.

Проверка с любой машины:

```
GET  http://{сервер}/{база}/hs/tsd/ping
```

Должно вернуть `{"ok": true, ...}`.

## 7. АРМ

Обработка `АРМРуководителяРевизии`: матрица зон + таблица.  
Кнопка актов: `АРМРевизии.МожноФормироватьАкты()`.  
Кнопка перепроверки: `АРМРевизии.НаправитьНаПерепроверку`.  
Монитор JSON уже собирает `АРМРевизии.ДанныеМонитора()`.
