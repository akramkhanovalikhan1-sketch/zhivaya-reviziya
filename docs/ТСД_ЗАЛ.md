# Прогон ТСД в зале (Алихан)

Сервер mock уже слушает `0.0.0.0:8000`. На АРМ в шапке появляются ссылки LAN — эту же ссылку открыть в Chrome на терминале.

Пример: `http://192.168.x.x:8000/tsd/`  
На терминале в поле «Сервер 1С / mock» оставить пусто, если страница открыта с того же адреса.

## DataWedge (Zebra / аналог)

1. Профиль: Associated apps → Chrome (или пакет браузера).
2. Keystroke output: **включен**.
3. Send ENTER: **да**.
4. Intent output: выключен, пока нет WebView.
5. Скан бейджа / зоны / товара должен печатать код и жать Enter.

Проверка без товара: на экране входа навести лазер на бейдж — должен сработать вход, как кнопка `EMP-1001`.

## Что смотреть

- Красная вспышка и писк на неизвестном коде.
- Список сканов и «Отменить последний скан».
- Потеря Wi‑Fi: скан остаётся в очереди, статус «оффлайн».
- Q-RC не стартует (карантин).

Когда Айдын опубликует 1С, в поле сервера указать `http://{сервер}/{база}` без `/hs/tsd`.
